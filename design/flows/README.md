# Flows

One Mermaid file per user flow, drawn by hand from the spec. Suggested set:

- `first-run.md` — install to the first useful screen
- `main-task.md` — the one job the app does, start to finish
- `settings-and-consent.md` — Settings, Privacy choices, ads consent

GitHub draws a ```` ```mermaid ```` block as a diagram. The measured screen map
(what the code can open today) is in `../README.md`.
